# CI isolation and coverage

The portable core-test workflow is designed for GitHub's `ubuntu-24.04` VM. It creates a transient systemd service with a minimal root, the checked-out source and host `/usr` toolchain mounted read-only, a private network, no root capabilities, a 512 MiB temporary writable filesystem, and a short environment allowlist. It requests CPU, memory, process, file-size and wall-clock limits. The service's own cgroup is bound read-only so a preflight can verify effective CPU, memory and process limits. The preflight also checks read-only mounts, temporary-disk size, per-process limits, blocked socket creation, blocked `io_uring_setup`, non-root identity, `no_new_privs`, and absence of home and service directories. If a check fails, the job stops before invoking CMake or the tests. No dependencies are installed by the build.

The job runs GCC and Clang separately on pushes to `main` and through `workflow_dispatch`. It does not run on pull requests: the sandbox-launching workflow must come from the trusted main branch, not from a proposed change to the workflow itself. Pull requests still receive the separately configured static and dependency checks. A Windows CI job is deferred until an equivalent fail-closed isolation environment is available.

CodeQL uses C/C++ `build-mode: none`, which analyzes source without invoking the repository's build. This may be less accurate than a traced build, especially for the SDK-dependent adapters whose headers are not provided. No CodeQL, systemd, compiler, FLAC3D plugin, or numerical test result is claimed until a corresponding run succeeds and its coverage is reviewed. In particular, a passing portable test does not demonstrate FLAC3D integration.

Systemd may disable unavailable sandboxing features rather than applying them; the preflight is therefore a required gate, not an optional health check. If the runner cannot provide or verify the limits, keep the job failed and fix the runner or isolation setup. Do not remove the checks or retry outside isolation merely to obtain a passing result.

# Security policy

For a vulnerability, use GitHub's private vulnerability reporting for this repository if the repository owner has enabled it. Do not publish exploit details, credentials, private model inputs or client data in a public issue. If private reporting is unavailable, first ask the maintainer for a private contact channel without including sensitive details.

The owner must enable or confirm private reporting in the GitHub repository settings. GitHub Actions are configured to scan for secrets and analyze the portable C++ core; they do not cover all proprietary SDK integration paths and are not a complete security audit.
